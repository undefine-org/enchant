# Packaged fonts

Downloaded from the primary Google Fonts source repository on 2026-10-24:

- https://github.com/google/fonts/tree/main/ofl/instrumentserif
- https://github.com/google/fonts/tree/main/ofl/dmsans
- https://github.com/google/fonts/tree/main/ofl/patrickhand

The adjacent OFL files govern redistribution. These are font assets, not renderer
code. The editorial build captures and hashes the exact bytes into each revision.

The product narrative film adds **Nunito** (variable weight), by the Nunito
Project Authors. Its rounded terminals provide a friendlier artwork/UI voice.
`Nunito-source.json` records the retrieved Google Fonts source and exact byte
hashes. The accompanying `Nunito-OFL.txt` must travel with the font. Canonical
shaping explicitly requires and hashes Nunito when requested; older specimens
continue to require only their original packaged set.

The ORA Ventures films add **Schibsted Grotesk** (variable weight), by the
Schibsted-Grotesk Project Authors, retrieved 2026-10-25. It is the display face of
the ORA Ventures website. `SchibstedGrotesk-source.json` records the source URLs
and exact byte hashes; `SchibstedGrotesk-OFL.txt` must travel with the font.
Canonical shaping requires and hashes it only when a request names it.
