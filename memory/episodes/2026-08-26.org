** ITEM Prototyped scheme (b) typed values for datalog-native plan (beam-lisp/scratch-proto-typed-values, real redb). DECIDED: scheme C — columnar tag-free typed value slot. Because a scan targets one attribute of one schema dtype, the value carries NO type tag; NIF told dtype by projection. Measured decode of 200k values: ETF 4.40ms → tag-free i64 0.12ms (37x); contiguous bulk-cast 0.04ms (100x); strings ETF 17.8ms → zero-copy view 1.99ms (9x).
