defmulti/defmethod/defprotocol/extend-type/extend-protocol are COMPILER special forms (not macros) so they intern into the current ns and work everywhere without a prelude load. Registry: ETS {:beam_lisp_vars} under {:multi,ns,name}, {:hierarchy,ns}, {{:protocol,ns,name,method},type_tag}. The multi var holds {:"$blfn", %{}, {0, fn args -> dispatch(...) end}} — the variadic tag (min 0) is REQUIRED because RT.invoke uses apply/2 which spreads a fixed-arity closure. Dispatch keys normalize vectors to {:"bl-vector", Enum.to_list(v)} for structural equality. defmulti redefinition preserves methods (Clojure CLJ-1351 — modern Clojure reuses the existing MultiFn, updating only dispatch; it is NOT a no-op). Dispatch fallback order: exact key → isa? hierarchy → :default → clear error. Protocol type tags via Multi.type_of/1 (builtin keyword tags; structs → module). extend-type requires ALL protocol methods (else clear error).
