DECISION: one function AOT.ns_closure_hash(ns) is the SOLE source of truth for tier-2 freshness, called by all three sites → symmetry by construction.

Tiers:
- TIER-1 = compiler_key/0 (KEEP public name; callers unchanged: aot.ex:545/950, compile.beam_lisp.ex:125/140, bootstrap.ex:100). CONTENT shrinks from whole-prelude to the closure of seed {compiler, core, sugar, data-readers, reader-node} = exactly 5 files (compiler→reader-node only; others→∅). Computed via DIRECT priv file reads (Path.wildcard + cheap declared-ns parse), NOT via Loader/Env — avoids bootstrap ordering fragility. MEMOIZED in :persistent_term (VM-constant). Still includes codegen beams + elixir/otp/vsn.
- TIER-2 = ns_closure_hash(ns) = hash_parts(sorted "<dep>:<sha256hex(dep_source)>" over {ns}∪transitive-:require). Reads sources via Loader.source_hash (fresh, no cache).

Wiring:
- emit (aot.ex emit_module): source_hash stamp = file && ns_closure_hash(ns) || nil (nil ⇒ in-memory ⇒ unstampable ⇒ trusted). Stamp pair = {ns_closure_hash, compiler_key}.
- runtime stale?/2: FIRST guard Loader.source_hash(ns) nil ⇒ not stale (prod, no source). Else beam_closure==ns_closure_hash(ns) and beam_key==compiler_key(). (replaces own-source src_hash compare)
- manifest :hash = ns_closure_hash(primary_ns) (was content_hash own-file); nil-ns files (priv/test.bl) fall back to content_hash. :key = compiler_key unchanged.

Why manifest MUST use closure hash: current own-content manifest doesn't rebuild a dependent when its DEP changes → dependent beam keeps OLD closure stamp → runtime rejects → recompile-every-boot. Closure manifest keeps build↔runtime in lockstep.

Safety asymmetry: manifest wrong ⇒ at worst needless rebuild (safe). Runtime gate is the correctness authority (independently recomputes closure). false-fresh impossible: closure hashes every dep content; ambient/reader deps (core/sugar/data-readers/reader-node) are in tier-1.

PERF: even unmemoized, ns_closure_hash beats today — today stale? calls compiler_key() (reads ALL 116 prelude files) PER ns; new reads only closure (avg ~8) + memoized tier-1. Strictly fewer reads.

Require-parse: shared AOT.ns_header(content)->{primary_ns,[requires]} via BeamLisp.Reader (strips comments — raw-text regex matches ':require' in comments, gave phantom interop→datom edge).
