beam-lisp's syntax-quote does NOT namespace-qualify symbols: `` `nav `` in a macro defined in ns A stays bare and resolves in the CALLER ns. Clojure qualifies to A/nav. Consequence for Specter: the same-ns macro-stack co-load (how test 04/05/23/24 are measured) works around this gap, but a faithful canonical cross-ns layout fails (defnav → `nav` undefined / `No protocol named …/RichNavigator`). The measurement convention (same-ns co-load) is a workaround for a real gap — documented in docs/specter-compat.md. Wave 28 measurement: load 25/31, behave 9/31 (05 defnav/defrichnav newly behaves; 23/24 newly load). Remaining wall is Specter's own impl machinery (i/NONE, i/direct-nav-obj, compiled-path cache, exec .select*), not beam-lisp core forms.
