Tagged-literal reader tags (#d, #time) in beam-lisp are registered from SOURCE, not hardcoded in Elixir. Central registry: priv/data-readers.bl, evaluated by BeamLisp.init/0 at boot (after core, before any user file is read). This is the self-hosted analogue of Clojure's data_readers.clj.

WHY the central boot-file (not per-library (data-reader! …) at the bottom of datom.bl / datom/time.bl): the live reader (lib/beam_lisp/reader.ex, via Compiler.eval_string -> Reader.read_string) reads a WHOLE file into forms before evaluating any of them. So a (data-reader! "time" …) sitting in the same file as the first #time literal in a requiring program has already lost the race. A boot-time registration never loses it. (priv/reader.bl is the self-hosted reader but is NOT live yet — its deferred-record-or-tag is a TODO; the live reader is still the Elixir one.)

THE BUG THIS FIXED (found via a race test): data_reader! stored a BARE STRING but the reader's record_or_tag clause only matches {:ok, {:symbol, _}}. So a .bl-registered tag returned {:ok, "name"} -> matched no clause -> crashed the reader with "no case clause matching {:ok, \"list\"}". The self-hosted data-reader! path was DEAD; #d/#o only ever worked through a hardcoded Elixir data_reader_default("d")/("o"). Fix: data_reader! now stores the whole {:symbol, name} node; data_reader/1 is a pure Env.lookup (no defaults); data_reader_default/1 DELETED entirely.

Env visibility: data-reader! -> Env.put_key writes at env_id() which stays :global during boot eval (new_env is a compile-context map, not an env binding; eval_string calls in_ns not with_env). data_reader -> Env.lookup walks chain() ending in :global. Cross-eval visibility confirmed empirically.

RENAME: #o -> #time (o too short; names the thesis). Swept across demos, test, docs, time.bl.

WHAT STAYS IN ELIXIR (justified): ONE branch in reader.ex record_or_tag accepting a STRING after a tag ([?" | _] -> ), so #time"…" works like Clojure #inst "…". This is pure LEXER GRAMMAR (what token may follow a tag), defines nothing about what #time MEANS. Can only move to .bl when reader.bl becomes the live reader. The [/{ collection branches predate this (commit 30bc124, #d query literal).
