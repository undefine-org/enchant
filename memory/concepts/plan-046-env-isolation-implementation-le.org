PLAN-046 shipped env isolation for beam-lisp (L1 prefix+chain, L2 Refs spawn propagation, L3 Sandbox/ExUnitCase/async runner). Hard-won facts: (1) :global.trans lock ids MUST be {resource, requester} 2-tuples — bare atoms and 3-tuples crash set_lock/4 (kernel 11). (2) Runtime Module.create (Record.define, Native.declare) races across concurrent envs loading the same ns — serialize with :global.trans. (3) ExUnitCase __using__ warm spec is AST — inject with plain unquote, NOT Macro.escape (and route the case through a resolve_base/1 fn to avoid unreachable-clause warnings). (4) A downstream case template must be an ExUnit.CaseTemplate forwarding `use BeamLisp.ExUnitCase` — a plain module leaves test/2 unimported. (5) bl suite async reaches the critical-path floor exactly (prelude_test.bl = 80% of suite → 1.24x; uniform relay subset → 3.0x). (6) The remaining async boundary: named app singletons (datom-conn-registry Agent) that apply bl fns in their own process run at :global — FUP-009. (7) Per-test env checkout ~40-60us; fetch tax ~+10% at :global.
