priv/veritas.bl unifies mock (∃), fault (∃¬), fuzz/coverage (∀ over guards) into ONE verb: (quantifier [var gen] pred) → modal verdict. Shipped + green (PLAN-064, DONE).

ARCHITECTURE (load-bearing decisions):
- Gen is a defprotocol over defrecords (IntGen/RealGen/BoolGen/StringGen/OneOf/TupleGen/AnyGen), NOT a multimethod on :gen/kind. WHY: multimethods are NAMESPACE-LOCAL — a defmethod registered in module A does NOT dispatch when called from module B that requires A. Records+extend-type dispatch GLOBALLY on the type tag. This was a real bug: multimethod version failed "No method for dispatch value :int" across the require boundary. Verified records work cross-require.
- Each gen implements gen-sample (fuzz), gen-enumerate (finite|:infinite → exhaustive engine), gen-constrain (z3 decls+asserts|nil), gen-tag. The generator IS the seam between the three engines.
- smt-of delegates to system.smt/of-source — the verifier's OWN translator — so veritas inherits Int/Real/Bool/String/enum theories free and never disagrees with the checker. Hand-rolled SMT fragment deleted.
- check ESCALATOR: constrain-able ∧ SMT-translatable → z3 (:proven|:refuted|:unknown); else finite enumerate → exhaustive (:proven|:refuted); else sample+shrink (:witnessed|:refuted). MODALITY is the whole point: run-sample returns :proven ONLY when exhaustive; a sample is :witnessed, never :proven.
- covers = ∀ over a fn's OWN guard clauses (system.model/transitions) → recovers fuzz.bl; :proven when domain finite (exhaustive coverage PROOF, upgrade over fuzz). faults = per-law (exists [v gen] (and (not law_i) rest)); :proven :none ⟹ law IMPLIED/redundant, z3-PROVEN (upgrade over mock/fault.bl which only un-witnessed it).
