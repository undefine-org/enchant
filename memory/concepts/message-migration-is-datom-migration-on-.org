Key insight for beam-lisp live-reload (PLAN-051): a message queued in a mailbox is an UNFULFILLED PROMISE — the sender promised the receiver a value of a shape it handles. Changing a module's message contract breaks that promise for every queued message. So a contract-changing edit bundle is INCOHERENT by the exact reload-coherence predicate (no dangling ref ∧ types check ∧ no unfulfilled promise), and a message-migration RESTORES coherence.

Two duals: quiesce = move TIME (wait for mailboxes to drain — "pending calmness", a QUERY over live mailboxes, termination provable via system.core/find-lasso); reroute = move DATA (transform each queued message old→new mid-flight via an interceptor).

Message-migration ≅ datom.migrate (priv/datom/migrate.bl) term-for-term, retargeted from datoms to mailboxes:
  :migration/grows↔:migration/modules; :migration/checks(data query)↔{:check :message-compat :to handler}; :migration/fn(db→tx-data)↔(old-msg→new-msg); plan(walk db, commit nothing)↔walk mailboxes; plan-with(spec remediate+check residual)↔spec migrate each msg+check new handler accepts; apply! :blocked gate↔un-migratable msg keeps old code serving; apply-batched! yield-writer↔draining yields to traffic; ledger-is-a-query↔quiescence-is-a-query.

Three existing mechanisms compose into live reload, no new engine: (1) reload transaction = Env.fork/isolated (same isolation the async test runner uses — validate candidate image in a fork, reject=drop fork, live image untouched); (2) in-place swap = Link.defvar/Emit.build_module (runtime defn IS a hot swap; do_load→eval→defvar means source-load=hot-swap); (3) verified migration = system.core/simulates? + examples/system/08_hot_upgrade.bl (code_change preserves simulation relation R). Old code serves through any incoherent hold because body modules BeamLisp.Ns.Fn.* are never reloaded→never purged (emit.ex:58); in-flight callers finish on their captured body. The incoherent window is unbounded and harmless.

Owner rule: guarantee lives in the RUNNING system not the build ("no live beam → too bad for you"); drop compile-time/CI staleness gates. Decision C: dev auto-reconciles in place, prod trusts beams (bounded).
