** ITEM A capability that ships absent reads as a bug: bundle it, and resolve it across tiers

A feature whose on-ramp assumes the *source checkout* (a Mix task, a fetch step, a dev-only command) is, in the shipped artifact, a feature that does not exist — and its error message then tells the user to run a command the artifact cannot run. The fix is not a better message: the capability ships WITH the artifact, and the ambient cache stays as the path a source tree uses.

Shape that worked (beam-lisp's code-embedding model, 2026-09-14):

1. Resolution over TIERS, first root that holds a COMPLETE copy, documented by what each tier buys:
   - explicit pin (env var) — SET MEANS ANSWER, never a fallthrough, or a test that pins an empty dir sees the machine's other copy and asserts the wrong thing;
   - bundled (`priv/<thing>/<name>`, fetched by the build before `mix release`, because a release packed without the payload cannot be fixed by packing harder);
   - ambient cache (per-machine, shared across checkouts/worktrees — right for the source tree, wrong as the only path).
2. A COMPLETION MARKER for "this copy is complete": the digest file the fetch writes LAST, after every artifact verified against its pinned sha. Not the biggest data file — a partial download must not look like a model — and a copy with no digest has no provenance.
3. The build step is idempotent and sha-verified per file, so a warm bundle costs one digest check and no network; a `--no-<thing>` flag (parse `no_thing: :boolean`; check `opts[:thing] == false`) is the slim-artifact escape hatch.
4. Redistributing third-party bytes means the notice travels: the fetch writes a PROVENANCE file (upstream URL, date, licence, pinned digests) beside the weights. Verify the licence from a primary source (HF API `cardData.license`), never from memory.
5. The diagnostic names the roots searched (`searched_dirs/1`), so absence is also the answer to "where did you look?"; a `tier/1` accessor lets a test or doctor say WHICH copy answered instead of inferring it from a path.
6. Prove the SHIPPED artifact, not the tree: run the built binary with the ambient cache hidden (`XDG_CACHE_HOME=<empty>`, env unset) and assert the feature answers; then the negative control (pin the env at an empty dir) must report absent. That pair is what proves the capability came from inside the artifact.

Cost is real and should be stated: the drop grew 99 MB → 130.4 MB (+32 MB of weights, which compress poorly).
