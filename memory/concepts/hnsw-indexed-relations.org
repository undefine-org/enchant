HNSW-indexed relations shipped (commit ee79c2d). Key lessons:

1. **Index-behind-provider state machine** (proven pure-bl first in bench/proto_index_lifecycle.bl): cold build / steady (0 reads) / WAL catch-up via `(history (since db cursor))` / tombstone-ratio rebuild / as-of bypass to exact. Soundness = as-of/since partition property → index-content ≡ corpus(basis) by induction.
2. **Value-checked tombstones**: hnsw_tombstone is eid-keyed but a retraction is about a VALUE. Post re-embed, retracting the old vector must not kill the new point. bl-side live-map {eid→dvec} checks values; Rust stays value-blind graph arithmetic.
3. **Index state key MUST include store identity** ([store attr params]) — two conns sharing a relation ident would corrupt each other's cursor.
4. **load_nif strictness**: the library fails to load if the crate exports a NIF the defnative block doesn't declare (caught vec_pack_rows). "Function not found 'Mod':name/arity" names the missing one.
5. **NifReturnable needs RefUnwindSafe** — asserted manually for HnswIndex (justified: all mutation via &self-concurrent hnsw_rs or Mutex).
6. **Measured honestly**: native-batch exact k-NN (vec_knn_all, one NIF call) has such a small constant it beats per-source HNSW searches below N≈1500; warm HNSW wins after (1.28x at 2000, diverging). Cold build = ~3x warm, amortized. Recall 0.99-1.0 vs exact oracle. Lever to lower crossover: batch-search NIF (all sources one crossing) — NOT yet done.
7. **bl conj is 2-arity**; multi-item conj errors "wrong number of args".
8. Catch-up runs INSIDE provider eval — reading index-state without an eval first shows stale state (bit my tests).
9. hnsw_rs 0.3.4: insert(&[f32], usize) &self-concurrent; process-exits if m>256 (clamp!); DistCosine via prelude; score = 1 - distance.

Environment: this repo has CONCURRENT agent sessions sharing the worktree — build-lock contention, others' file deletions breaking compile.beam_lisp (source_dirs priv + spell/src), stale manifests. Mitigations: private MIX_BUILD_PATH, per-source-dir compiles, pkill only own /tmp-script runs, commit early.
