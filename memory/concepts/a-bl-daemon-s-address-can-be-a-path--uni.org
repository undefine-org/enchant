Verified 2026-09-16 in beam-lisp:

* raw: `gen_tcp.listen(0, [:binary, {:active,false}, {:ifaddr, {:local, path}}])` → `{:ok, sock}`; `gen_tcp.connect({:local, path}, 0, opts)` → `{:ok, sock}`; accept + recv round-trips.
* Bandit in a bl program: `(web/serve {:port 0 :plug router :ip {:local path}})` logs `Running … with Bandit 1.12.4 at <path> (http+unix)` and answers a real `HTTP/1.1 200 OK` over the socket. So the server every `bl serve` app uses needs no TCP port.

Consequences worth keeping:
* an address can be DERIVED (`<runtime-dir>/ports/<tree_id>.<name>.sock`) instead of allocated: unique by construction, no collision, no probe-then-bind race, nothing to clean up but an unlink on terminate;
* it is also a security improvement: a 0700-directory unix socket is this user only, where any local process can connect to `127.0.0.1:<port>`;
* the allocator becomes "hand out a bound socket, not a number" (`gen_tcp.listen(0, …)` + `controlling_process/2`), which deletes the TOCTOU window in probe-then-release-and-rebind;
* foreign servers (vite, cargo, python, a binary we did not write) cannot take a path — they get an ephemeral port handed over in `$PORT`, and the number then lives only in that process's environment and in the registry, never in a URL.
* `{:ifaddr, {:local, Path}}` means the socket file exists as a socket, not a regular file — `File/regular?` is the wrong check.
