loom (priv/loom/) is beam-lisp's "grammar of the web" — a small closed set of composable value-primitives (mark/style/layout/encoding/data/event/reconcile) that express any web app. Modules: token.bl (design-token scale + sx flat atomic class + sx* composite class carrying :on pseudo + :at media rules, cascade-sorted small→large; a brand is a deep-mergeable per-process value), box.bl (THE layout algebra — one `box` primitive over every flex/grid axis, responsive :at, stateful :on, raw :style escape hatch that WINS, attr-forwarding, author-:class append; named points col/row/wrap/grid/center/spacer), ui.bl (accessible components built on box: button/field/checkbox/select/card/badge/alert/divider/skeleton/heading/prose/link — a11y baked in: label-for-id, aria-invalid+describedby+role=alert, disabled-drops-handler), transform.bl (the view is DATA so path-algebra transforms it: retheme/retarget-events/expand-aliases/find-nodes/audit-missing-labels/map-text over hiccup via rewrite/postwalk+specter), form.bl (form-for: derive a form from a datom schema VALUE, input kind by :db/valueType).

CORE PRINCIPLE — NO CEILING: every scale prop takes token-OR-raw (:gap :4 | "13px" | 13), every primitive has a :style escape hatch merged LAST that wins, arbitrary attrs forward, author :class appends. loom never restricts consumer apps.

SELF-CATALOGING: tooling/catalog.bl (library) + run-catalog.bl (entry) build a live catalog app from a DATALOG QUERY over ^:catalog-tagged defns in a source dir (BL_CATALOG_DIR, default examples/loom). Pattern mirrors codebase.bl/system/facts.bl: eval each .bl (defns become live/callable), read each (line+src), project one datom per defn (catalogued? group/title/doc/tags), query groups/entries/tags/counts/coverage. The live example is the fn resolved by ns+name (BeamLisp.Env/fetch) and called. Drop a ^:catalog defn in the dir → it appears, zero catalog code changes.

KEY GOTCHA (fixed): with-sheet must REALIZE the hiccup tree (force lazy `for` children) BEFORE capturing the stylesheet — else sx calls inside lazy children fire after style serialization and their classes go missing. token.bl/realize keeps seqs as seqs (hiccup rejects a vector where a bare child-list is expected). This is a general trap for any atomic-CSS-collected view using `for`.
