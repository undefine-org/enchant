SHIPPED. beam-lisp AOT freshness is now two-tier, replacing a single whole-prelude compiler_key that forced `building 116 source(s)` on ANY .bl edit (cold serial build 511s/16-core).

ARCH: BeamLisp.SourceGraph (lib/beam_lisp/source_graph.ex) is the SINGLE source of truth — pure, Env-free `(ns …)` header parse + `closure_hash/3` (ns + transitive :require closure). Build-stamp (AOT.emit), runtime-gate (AOT.stale?/2), and Mix manifest (compile.beam_lisp up_to_date?) ALL route through it ⇒ symmetry by construction. Break symmetry ⇒ runtime recompiles from source EVERY boot (the failure mode; verify with: 2nd `mix compile`=noop AND runtime ensure_loaded→:loaded not :no_module).

TIERS:
- TIER-1 compiler_key/0 (AOTCache): narrowed from whole priv/**/*.bl to closure of @toolchain_seeds = {compiler, reader-node, core, sugar, data-readers}. WHY those 5: compiler+reader-node run at compile time for every ns; core+sugar are ambient (env.ex:762 unqualified-lookup fallback, no :require edge); data-readers seeds tagged-literal registry consulted at READ time (no edge). These IMPLICIT edge-less deps can't be seen by per-ns closure hashing → must be global. Memoized in :persistent_term.
- TIER-2 AOT.ns_closure_hash/1,2 (aot.ex): per-ns closure. emit uses /2 with file-seed (isolated --out build's primary ns won't resolve by name — only <dir>/<sub> on load path — so seed its {hash,requires} from the known file; transitive deps resolve by name). runtime uses /1.

RESULTS: true-leaf edit → building 1 (was 116); datom.vector → 23 (its dependent closure — cross-ns defmacro means dependents MUST restage, sound not wasteful); tier-1 edit → all (correct). O(N) boot cost gone (memoized + reads only closure ~8 files vs old per-ns whole-prelude 116).

GOTCHAS: (1) Reader.read_all needs BeamLisp.Env running → NOT usable in compiler_key (runs in Bootstrap.install! BEFORE init) → SourceGraph.header is a pure scanner instead. (2) raw-text `:require` scan matches COMMENTS → phantom edges (interop→datom); SourceGraph strips comments (string-literal aware). (3) narrowing compiler_key rotates it → regenerate priv/bootstrap/seed via `mix run priv/bootstrap/gen_manifest.exs` after copying fresh compiler-closure beams; non-fatal while genesis backend exists. (4) hash encoding must match across sites: sha256|>Base.encode16 (content_hash/source_hash upper; SourceGraph.hash_lines lower — closure hashes only ever compare closure-to-closure so internal consistency is what matters).
