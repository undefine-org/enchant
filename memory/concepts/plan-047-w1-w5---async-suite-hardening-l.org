PLAN-047 W1-W5 lessons (beam-lisp 9e00c0f, 33e35c3, 033a9e6): (1) Async suites forced the doctrine: required namespaces = library code = load at :global, always (source AND AOT replay); test files evaluate into forks. Clojure's model: libraries global, your ns yours. (2) current_ns must be pdict-first at EVERY env — Agent-backed global ns let concurrent loads cross-compile each other's namespaces. (3) mark_loaded AFTER eval, cycle-cut via pdict :bl_loading set — mark-first lets concurrent requires see loaded-but-empty. (4) Module.create races need serialization at Emit.build_module (per-module trans) — per-path locks fail on multi-ns files. (5) LazySeq.ensure_table 'owned by whichever process gets there first' = VM-wide death when that's an async task; pinned to new BeamLisp.Loader.Server (all :global loads run there; ETS tables created at load outlive tasks; nested requires inline via pdict flag; on-demand start for compile VMs + cleanup in compile.beam_lisp). (6) Lock-order: never hold a trans lock then GenServer.call the server — route THROUGH the server at the top. (7) process_flag(:max_heap_size, %{kill: false}) — integer form exits :killed, untrappable, kills awaiting callers through task links. (8) Relay suite needed a serial pass for OS-process-global couplings (RELAY_ADMIN_TOKEN mutated by 3 files) — bltest partitions; 123/385 identical totals both modes, 11s→9s. (9) mix compile.beam_lisp silently no-ops on priv edits (FUP-011) — workaround: AOT.compile_file directly. (10) Biscuit expr encoder doesn't exist (expr.bl decode-only) — W4 blocked on it.
