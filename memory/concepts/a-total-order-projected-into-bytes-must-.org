** ITEM A total order projected into bytes must be projected everywhere, including the types you cannot write as literals
:PROPERTIES:

:CONFIDENCE: 0.6
:CREATED: 2026-08-22T11:55:17Z

Context: beam-lisp Datomic. `RT.compare/2` is the sole authoritative
total order; `priv/datom/codec.bl` encodes values into order-preserving
byte keys, so its tag order MUST project compare's ranks.

The rule was stated in a comment directly above the tag constants. The
constants violated it three separate times, each caught by a different
mechanism, each time in the types the previous mechanism could not see:

1. Ints vs floats vs bignums — caught by a literal-based property test.
2. Opaque tags (pid/port/ref/fun) relative to EACH OTHER — invisible to
   that property test, caught only by a reviewer probing by hand.
3. Opaque tags relative to COLLECTIONS — caught the moment the property
   test's sample was widened with runtime-constructed opaques (242 of
   3,600 pairs).

THE LESSON: a property test is only as good as the shapes it can
CONSTRUCT. Its sample was a literal vector, and a pid, port, reference
or function cannot be written as a literal. The four types the sample
could not reach were exactly the four that were wrong — not by
coincidence: they were unreachable to the test AND to the author's
intuition for the same reason.

When a test generates its own inputs, audit what it CANNOT generate.
That set is where the bugs are.

Corollary found the same way: `=` raised `protocol Enumerable not
implemented for Function` for any function that was not arity-2,
because Elixir implements Enumerable for arity-2 funs (reducers) and
the lazy walk tried to enumerate. `=` must be TOTAL — every collection
holding a function was a landmine, since distinct/set-membership/
contains? all route through it.

And one honest limit: two distinct closures CANNOT be ordered
consistently with compare. A durable key must come from
`term_to_binary`; compare falls through to a per-VM fun identity that
changes across restarts. Pinned as a known property (round-trip,
self-equality, stability guaranteed; relative order not) rather than
asserted away.
