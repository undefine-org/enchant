## The pattern

Twelve defects in one build shared a shape: **the artifact PARSED, so every
structural check passed, and it was silently wrong.**

- template body emitted, declaration not → `@each` invoked a template the file
  never declared; document valid, log empty
- `&bubble("$m")` → re-parses as a string LITERAL; template gets 2 characters
- `@data signal $inc() to $counter;` → body dropped; a signal that sends
  nothing and decodes nothing
- `@template &shell { … }` (no parens) → parses to ZERO matches; declaration
  evaporates, file looks fine
- `data-role=`$m.role`` unquoted → HTML tokenizer reads it as a literal; page
  renders, every `[data-role='user']` rule silently misses

None failed a test, because the tests compared the emitter to the shape the
emitter INTENDED. An invented wire key is perfectly self-consistent.

## The rule

To test a generator, do not assert on its output. **Feed the output to the
consumer and ask what it MEANS**, then count what survived.

  emit → print through the real printer → re-parse → count forms

3 templates in, 1 out. That subtraction found what no assertion had.

## Corollaries

**Adjacent properties.** Each test measured something NEXT to what mattered:
fidelity instead of addressability, structure instead of content, round-trip in
one direction instead of both. A gate only fails on the property it measures.

**Byte size proves the process ran, not that it worked.** A screenshot of a
page whose bundle bound nothing is a plausible 76 KB. Ask the DOM.

**Verify before you capture, not after.** Screenshot-then-check is two loads
that can disagree — reviewed as theoretical, bit for real on the next run.

**Review the fixes.** A fourth swarm over the FIXES found four more defects,
including one introduced by a fix (an over-eager `=` heuristic) and one the
first swarm's fix had missed (the host still copied the shell it should emit).

**A table of five yeses reads as a closed loop.** Prose qualification below it
does not survive skimming. Give the gap its own row.
