** ITEM A name needs no port only if port 80 answers — install the redirect, then print from evidence

A printed address must be one a client can use. The port in `http://web.pulse.test:7777/` is an implementation detail — EXCEPT when leaving it out is a lie, because port 80 is the only HTTP port a URL may omit and something has to answer there.

THREE PARTS, AND THEY ARE ONE DECISION

1. **Answering port 80 is the user's environment, not our code.** The gateway prefers 80 and falls back to 7777 with a sentence saying why. Two ways to make 80 answer, and the SMALLER one is the default:
   - `bl install redirect` — one nftables table sending `127.0.0.0/8:80` and `[::1]:80` to the gateway's port, plus a system unit that reapplies it at boot. Loopback only, removable, no machine-wide policy change. It needs root, so the verb RUNS its script with `sudo -n` when it can and otherwise PRINTS it verbatim — a tool that blocks on a password prompt in a pipe is worse than one that hands over the line.
   - `net.ipv4.ip_unprivileged_port_start=80` — one sysctl, and the cost (any local process may bind 80–1023) is printed next to it. Named as the alternative, with its price visible.

2. **Which one is in force is never configured and never guessed.** A redirect rewrites the packet, not our sockets, so no socket option can see it — `Gateway.fronted_on?/1` PROBES port 80 and asks whether a beam-lisp gateway answers (a connect plus a read of the head, looking for the `x-bl-gateway:` marker). The printed address therefore follows EVIDENCE: install the redirect and the port drops out; remove it and the port comes back, with nothing to reconfigure and no stale state to explain.

3. **The rule is pure; the facts are resolved once.** `url(host, port, fronted?)` decides the string; `url/1,2` supply the live facts; `Gateway.live/0` resolves them ONCE per render (one runtime-dir read, at most one probe) and the callers — the read-model, the JSON face, `bl ports` — pass them down. Asking per row costs N file-server round trips and N probes, which on a loaded machine is a client timeout while drawing a page. Same shape on the bl side: `live` + `url-for*`, with `url-for` for a single address.

CONSEQUENCE WORTH KEEPING: a probe-based rule cannot be asserted with a fixture. Tests assert the PURE rule (`url/3`) and separately prove the probe with real sockets — a test that calls `url/2` is a test of the machine it runs on, not of the rule.
