* Reproduction
From a coherent source/floor at the source workspace milestone c5d7f539:
#+begin_src sh
scripts/demo-artifact-production --out .local/execution/new-probe --bootstrap-probe
#+end_src
Run under the documented process-tree memory/time limits. The producer and
fresh artifact consumer pass; the independent third phase selects the actual
priv/boot/rt.bl with the quoted-symbol prepare_unit API.

The new preparation path refuses with
=:cyclic-sdk-constructor-compilation=. Bounded native tracing identifies the
cycle: Core's cond macro calls Rt.empty?, source rt/empty? calls rt/k-empty?,
and compiling rt/k-empty? requires cond again. The next invocation demands the
same unfinished rt/k-empty? compilation.
The optional probe asserts physical runtime identity and scoped generation
preservation on success AND refusal. No candidate floor is installed.

This is distinct from the original regenerator failure
[[file:BUG-bootstrap-self-rebuild-publishes-into-protected-seed.org][intermediate publication over protected seed routes]]. The production consumers
have not yet migrated to prepare_unit, so that original bug remains open too.

* Diagnosis and next implementation
[[file:../../research/execution-protocol-audit/staging-architecture.org][The staging architecture investigation]] includes a minimal reproduction,
ordinary/mutual recursion controls, value cycles, invocation IR equivalence,
an unused-require control and every actual floor namespace. The independently
identified Core blocker is local cond use before its declaration. The native
research harness asserts current outcomes; bootstrap acceptance remains open.

Source remote selection currently depends on the visited unit set. An implicit
language invocation and an explicit Rt.invoke also have identical ANF. Introduce
explicit compilation-world binding identity and canonical language-invocation
semantics, with a qualified preceding-phase macro provider for bootstrap.
Convert the minimal cases into the corresponding desired-behavior regressions
as that implementation lands.

Preserve the distinction between verified compiler-kernel operations and
source-selected helper semantics. Reuse anf/system.ir for executable grammar
and codebase facts for source dependencies. Do not bypass all Rt source calls,
execute arbitrary helpers natively, relax SDK custody, or treat a caller tag
as kernel authority to make this probe green.

* Acceptance
The actual runtime unit prepares/emits without touching loaded runtime code,
and a focused case distinguishes ordinary recursion, invalid compile-time
cycles and compiler ABI calls. Full host/boot reproduction remains the later
gate; success of one runtime unit is insufficient to claim self-hosting.
