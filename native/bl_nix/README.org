#+title: First-party Nix codec

=bl_nix= implements the grammar and byte traversal for =nix= and =nix.native=.
=rnix= supplies the Nix concrete syntax tree. The crate parses losslessly,
prints existing trees, projects plain data and emits fresh Nix expressions.

The Source policy lives in =priv/lib/nix.bl=. =build.backend= uses that API to
compile backend descriptions and check the inverse projection. Native products
use the same per-crate Nix manifest and verification path as the other SDK NIFs.

The implementation originates in Foundry commit
=5181082feaa45df545f1d851ea9f0c9a0d1ec97c=. Beam Lisp owns this copy and its
dependency lock. Native vectors include the current runtime's =meta= field.
The codec has no Foundry runtime dependency.

Run the Rust laws through =test/nix/nix-codec-rust.nix= and the Source laws
through =test/bl/nix_test.bl=. =test/nix/backend-codec.nix= qualifies the native
codec and description compiler in one bounded private Source world.
