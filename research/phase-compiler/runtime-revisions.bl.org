#+TITLE: Logical worlds, immutable physical runtime revisions

* What a revision owns

A logical namespace/revision belongs to the selected compilation world. A BEAM
module name belongs to physical code. Default builds now derive that name from
the complete captured inputs, compiler/build keys and pipeline body/interface
identities. A fixed logical target is the domain tag for hashing; the resulting
physical name is then recorded in the ordinary artifact selection. This avoids
a self-referential hash and does not introduce another cache or code registry.

=compile.world/runtime-module= exposes this deterministic selection for a
capture. Builds reuse the same identity calculation. Equal selections recover
the same module; changed code or compiler pipeline selects another module.
The existing native Loader's exact-byte check still protects every module.
Explicit low-level target module arguments keep their existing semantics.

An old returned closure and a new compiled program can consequently coexist.
The existing Env borrow/retirement fence owns their code lifetime. Publishing a
new disk selection never purges a loaded old revision. Closure-free entries
still retire; escaping local functions still conservatively keep their code.

* One selected disk unit

The existing workspace claim serializes publication. Only a captured,
byte-verified previous artifact unit proves ownership of obsolete member names.
New members and the manifest publish first, then those obsolete files retire.
Runtime files must still match their captured previous bytes before cleanup;
changed files refuse before the new unit is published. Foreign files retain
the earlier refusal/preservation behavior. A damaged unit can be repaired at
its known current selection; unknown stale members require explicit recovery.
This is fail-closed publication, not an atomic directory-swap or a new crash
recovery guarantee.

* Executable warm coexistence

#+begin_src beam-lisp :id contextual-runtime-revisions
(ns compilation.runtime.revisions.walkthrough
 (:require [build :as build] [compile.world :as world]))
(let [root (Path/join (System/tmp_dir!) (str "runtime-revision-demo-" (erlang/unique_integer (list :positive))))
      main (Path/join root "main.bl") manifest (Path/join root "world.bl")
      opts {:world manifest :out (Path/join root "build")}
      module-of (fn [result] (first (:modules (first (vals (:runtime-manifest result))))))]
 (File/mkdir! root)
 (try
  (File/write! manifest "{:version 1 :profile 'syntax-v1 :entry ['main 'current] :sources [{:namespace 'main :revision 'current :file \"main.bl\"}] :libraries []}")
  (File/write! main "(ns main) (fn [x] (erlang/+ x 40))")
  (let [old (build/run opts) _ (assert (empty? (:errors old)))
        old-module (module-of old) old-value (world/run-unit (:out old) [])]
   (try
    (File/write! main "(ns main) (fn [x] (erlang/+ x 50))")
    (let [new (build/run opts) _ (assert (empty? (:errors new)))
          new-module (module-of new) new-value (world/run-unit (:out new) [])]
     (try
      (assert (not= old-module new-module))
      (assert (= 42 (old-value 2))) (assert (= 52 (new-value 2)))
      (assert (= 3 (count (File/ls! (:out new)))))
      {:old (old-value 2) :new (new-value 2) :distinct-modules true :unit-files 3}
      (finally (BeamLisp.Env/retire_module! new-module))))
    (finally (BeamLisp.Env/retire_module! old-module))))
  (finally (File/rm_rf! root))))
#+end_src
