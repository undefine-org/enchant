#+TITLE: Phase values can own closures without serializing live functions

* Values belong to a world, phase and owned expansion session

A phase-qualified binding names a declaration at a particular effective phase.
Its value can now be an interpreted closure that captures lexical data or an
earlier interpreted closure. It is initialized once per effective binding in
one expansion session. Import aliases preserve that binding; revisions and
phase shifts preserve their distinct identities.

The existing bounded ANF constructor still owns evaluation. A session retains
values under opaque IDs and supplies them as compiler-owned ANF locals. No new
evaluator, native primitive policy or Source lookup fallback is introduced.
Normal macro responses discard temporary callable ownership. Bound values and
their witnesses remain until session close; failures poison the session.

* Archive recipes, then specialize bracket literals

                             " (syntax-literal (specialise (:value (syntax-arg form 1)))))")}
      archive (x/decode-phase-library (x/encode-phase-library (x/phase-library [provider])))

                [{:namespace 'client :revision 'current :file "client.bl"
                  :source "(ns client) (import-world 'forms 'old :only [answer]) [(answer 2) (answer 3)]"}]

* Bounded storage and effect denial

=bind_constructor_session!(session, ANF, locals, bindings)= evaluates once and
returns an opaque value ID. =eval_constructor_session!= retains its three-arg
API and adds an optional fourth argument mapping ANF local names to IDs owned
by that exact session. Public locals and returned results remain first-order.
IDs cannot be borrowed by another session/process or supplied as native input.

One session has at most128 stored values. Existing execution, walk, allocation,
callable and recipe ceilings remain shared. Retained storage has a conservative
16MiB accounting ceiling based on bounded syntax/data costs and the existing
allocation ledger. It is an accounting bound, not measured RSS. Storage does
not serialize captured function graphs: repeated shared captures can otherwise
expand when represented as ETF. A regression retains14 closures with repeated
shared captures and requires bounded accounting while returning42.

A closure that attempts erlang/put when called later still refuses under the
same primitive policy, leaves no effect and poisons its session. Closing releases
the interpreter frame and values, including after failure. These compile-time
ownership rules grant no application/native execution authority.
