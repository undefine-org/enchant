#+title: Deterministic clause identities and the bootstrap kernel

* One artifact, two kinds of identity
The compiler groups canonical clauses by physical function and arity, then
hashes deterministic term encoding with SHA256. Clause order, guards and literal
values remain significant. Native map/set iteration order and VM-local atom
creation order must not change the result. The compiler key binds the toolchain;
this is not a promise of identical encoding across OTP versions.

#+begin_src beam-lisp :id clause-identity-values
(ns research.clause-identities (:require [anf :as anf]))
(let [clause {:op :defn-clause :fname :answer :params [] :guard nil :ann {}
              :body (anf/lit (MapSet/new (list :alpha :beta)))}
      identify (fn [value] (anf/execution-clause-identities [value]))
      digest (get (identify clause) (tuple :answer 0))]
 (assert (= 32 (erlang/byte_size digest)))
 (assert (= (identify clause)
            (identify (assoc clause :body (anf/lit (MapSet/new (list :beta :alpha)))))))
 (assert (not= (identify clause) (identify (assoc clause :body (anf/lit 43)))))
 {:full-sha256 true :literal-values-preserved true})
#+end_src

* The executing kernel is not the target Source world
Recovery runs an earlier compiler to produce a candidate from changed Source.
Its constructor kernel must be authenticated against the actual executing
floor. Its target Source must be bound to the current physical Source key.
Equating those identities made legitimate artifact-only recovery fail with
stale_sdk_bootstrap_inventory after a compiler edit.

Preparation now captures its kernel manifest internally. Kernel modules still
require manifest SHA/loaded-code proofs, code leases and protected forwarder
routes. Manifest changes refuse, and all acquired leases unwind on failure.
Kernel phase recipes carry that manifest's compiler key; the target workspace
retains its independently validated current Source key. Public phase_library!
and runtime SDK seed checks retain their current-key requirement. No caller
option supplies a kernel manifest or creates SDK authority.

                     (str "documented-kernel-world-" (erlang/unique_integer (list :positive))))

  (File/write! file "(ns documented.kernel.example) (defn answer [] (cond :else 42))")
  (let [workspace (BeamLisp.AOT/open_workspace
                   {:version 2 :phase-imports (list 'core 'sugar)
                    :sources (list {:namespace 'documented.kernel.example :file file})} {})]
   (try
    (let [prepared (BeamLisp.AOT/prepare_unit workspace 'documented.kernel.example)]
     (assert (= :source-compilation-world (get-in prepared [:world :kind])))
     (assert (= :kernel-phase-world (get-in prepared [:phase-world :kind])))
     (assert (not= (get-in prepared [:world :id]) (get-in prepared [:phase-world :id])))
     {:source-world true :kernel-phase-world true :published-target false})
    (finally (BeamLisp.AOT/close_workspace! workspace))))
  (finally (File/rm_rf! root))))
