#+TITLE: One prepared world, runtime code and a phase-only artifact

* Shared preparation, existing artifact ownership

=expand/prepare-program= shares the same parsed catalog, binding worlds and
bounded constructor session as =expand/program=. It returns the runtime program
and a declaration-only phase library. The latter deliberately omits the entry
expression: importing a provider cannot run the application's entry point.
Original binding identities, private helper recipes, compile-time closures and
source coordinates remain in the archive. The original provider-only archive
API still rejects sources with entry expressions.

=bl.world/prepare-unit= adapts a prepared world to AOT's existing prepared-unit
format. AOT emits and verifies both members through its complete membership and
physical input/compiler drift checks. The runtime member has =run/0= plus
binding metadata; the phase companion contains bounded recipe data. Reading a
unit checks actual files and decodes the companion without loading code.

=bl.world/read-unit= exposes =:runtime-beams= for runtime packaging and
=:phase-library= for fresh compilers. A phase provider does not need to ship
with the runtime program. Neither an artifact hash nor a phase report grants
native execution admission. Native effects and broader analysis obligations
retain their existing scope.

* The bracket grammar becomes a portable build input

#+begin_src beam-lisp :id paired-phase-unit
(ns phase.artifact.unit.walkthrough (:require [bl.world :as world] [expand :as expand] [lower :as lower]))
(let [directory (Path/join (System/tmp_dir!) (str "phase-unit-demo-" (erlang/unique_integer (list :positive))))
      prepared (world/prepare "test/fixtures/contextual-validation/world.bl")
      unit (world/prepare-unit prepared :Elixir.PhaseUnitDemo)]
 (try
  (BeamLisp.AOT/emit_unit unit directory)
  (let [verified (world/read-unit directory)
        library (:phase-library verified)
        imported (expand/program
                   [{:namespace 'consumer :revision 'current :file "consumer.bl"
                     :source "(ns consumer) (import-world 'validation 'current :only [ratio]) (ratio [80 2] 99)"}]
                   ['consumer 'current] [library])
        value (lower/eval-anf :Elixir.PhaseUnitDemoConsumer (:node imported))]
   (assert (= 42 value)) (assert (= 1 (count (:runtime-beams verified))))
   (assert (not (erlang/module_loaded :Elixir.PhaseUnitDemo.PhaseLibrary)))
   {:result value :runtime-modules (count (:runtime-beams verified)) :phase-provider-loaded false})
  (finally (File/rm_rf! directory))))
#+end_src

The companion is compile-time data. Its private closure rebuilds in the fresh
importer's owned constructor session, specializes the bracket form to42 and
leaves its validator, division and catch helper out of the generated expression.
The native runtime member independently runs the complete original entry.

* Remaining integration

This is a compiler-to-artifact-unit connection. Default project build/cache,
Loader selection and release packaging still need their explicit integration
and cold/restart/tampering gates. No cache hit or source-free process claim is
made merely because an in-process compiler consumes archived provider recipes.

* Opaque inputs keep their bytes

An artifact input declares whether it is normalized Source or opaque bytes.
Legacy Source inputs retain the established Loader normalization. World units
capture every selected physical file as bounded raw bytes, including selection
manifests and phase archives. The common AOT input gate checks the same kind
before emission and again before publishing the completed unit manifest.

The initial adapter treated all inputs as Source. Loader's Markdown fallback
could turn both a binary archive and a non-Source selection file into empty
code. Changing those files therefore went undetected. An actual control passes
23 assertions but fails4 new drift assertions: both changed inputs are accepted
and output is written. The raw-byte kind fixes the shared protocol rather than
adding a separate check that only the world CLI knows to run.

The corrected candidate passes259 assertions across10 files, including29 unit
assertions. Both opaque-input changes now refuse before creating output.
A separate added case exports an application's public helper from a module
whose original entry raises: a fresh archived import returns42 without
executing the application entry. The final three-process demo also passes on
the compiler containing the raw-byte input fix.
