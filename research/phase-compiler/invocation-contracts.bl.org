#+TITLE: Immutable callable-data arities across compiler and typed analysis

The Compiler already owns the callable-data arity table used when checking a
literal call head. Its public =ifn-arities= Var is a compatibility value and can
be rebound in a namespace environment. =typed= previously read that mutable Var;
rebinding it could suppress a valid warning without changing runtime behavior.

=compiler/invocation-arities= now exposes the compiler-owned immutable value as
a native function. Both the compatibility Var and the function's Source value
can be masked without changing a compiled direct call. =typed= calls the API;
its existing union rule still leaves a possible function/unknown arity alone.
The private literal remains the one table. There is no boot dependency on
=typed=, =system= or =codebase=.

#+begin_src beam-lisp :id compiler-invocation-contract
(ns phase.invocation-contract.walkthrough (:require [compiler :as compiler] [typed :as typed]))
(let [contract (compiler/invocation-arities)
      warnings (:warnings (typed/check-source
                 "(defn run [] (let [f :answer] (f {} 1 2)))" "invocation.walkthrough"))]
 (assert (= [1 2] (get contract "kw")))
 (assert (= [1] (get contract "vector")))
 (assert (= [:arity] (mapv :kind warnings)))
 {:keyword (get contract "kw") :vector (get contract "vector")
  :warnings (mapv :kind warnings)})
#+end_src
#+RESULTS: compiler-invocation-contract
: {:keyword [1 2], :warnings [:arity], :vector [1]}


Native dispatch controls check every count from0 through3 for keywords, maps,
sets and vectors. Scope-masking controls reproduce the lost-warning failure
and verify that neither compatibility data nor a function-value rebinding can
change the compiled API. Compiler kernel checks still audit actual emitted ANF.

This table covers callable data. Native function and tagged dispatcher arities
come from =system.ir/function-shape=; =system.arity.anf= follows those contracts
through lexical flow. Its present callable-data values remain unknown rather
than assuming a type from an arbitrary struct field. Broader value/type flow is
subsequent work.
