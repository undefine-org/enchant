#+TITLE: Contextual programs become ordinary compiled runtime packages

* The boundary

The compiler emits a runtime/phase pair. =compile.world/package-runtime!=
projects that verified pair into a new directory containing only the runtime
BEAM and the existing =artifact-unit.term= manifest. It reuses the AOT emitter,
byte verifier and workspace claim. The phase archive stays with the compiler.

=bl run ARTIFACT_DIR= enters =BeamLisp.Loader/run_artifact_unit=. The Loader
validates actual bytes, contextual roles and compiler identity before publishing
code. It inspects executable instructions to refuse =on_load= before loading;
OTP does not retain that information as an ordinary attribute. Publication and
code retention share Env's existing physical-module fence. User code runs after
that fence has been released. There is no additional registry or callback queue.

A successful closure-free entry retires after its last borrow. Local functions
may escape in returned values, so their module remains available. Different
bytes for an already loaded physical module refuse before replacement. Failed
entries retain code for stacktraces. Immutable versioned module selection and
automatic retirement of escaped closures remain separate work.

* Usage

#+begin_example
./bin/bl build
./bin/bl world pack build/artifact-unit --out runtime
./bin/bl run runtime -- first second
#+end_example

The manifest and runtime bytes are sufficient on a compatible beam-lisp image;
this is not yet a standalone OTP release. Compiler-key matching is deliberately
conservative. Producer/target ABI separation and broader SDK release packaging
have their own remaining gates.

* Executable projection and entry

#+begin_src beam-lisp :id contextual-runtime-package
(ns compilation.runtime.package.walkthrough (:require [compile.world :as world]))
(let [root (Path/join (System/tmp_dir!) (str "runtime-package-demo-" (erlang/unique_integer (list :positive))))
      unit (Path/join root "paired") package (Path/join root "runtime")]
 (File/mkdir! root)
 (try
  (BeamLisp.AOT/emit_unit
   (world/prepare-unit (world/prepare "test/fixtures/contextual-validation/world.bl")
                       :Elixir.ContextualRuntimeWalkthrough) unit)
  (world/package-runtime! unit package)
  (File/rm_rf! unit)
  (let [value (BeamLisp/run_file package)]
   (assert (= [42 99 42] value))
   (assert (= 2 (count (File/ls! package))))
   (assert (= false (erlang/module_loaded :Elixir.ContextualRuntimeWalkthrough.PhaseLibrary)))
   (assert (= false (erlang/module_loaded :Elixir.ContextualRuntimeWalkthrough)))
   {:value value :runtime-files 2 :phase-loaded false})
  (finally (File/rm_rf! root))))
#+end_src

* A cold reader must own its wire vocabulary

The first real fresh consumer refused before publication: the manifest's safe
ETF decoder encountered a fixed coverage atom known only to a producer Source
namespace. AOT now owns the fixed artifact wire vocabulary and uses the bounded
closed-ETF decoder. Reading data neither loads producer namespaces nor creates
arbitrary atoms. The failing fresh-process receipt remains a regression control.

The corrected three-process demonstration passes producer/restorer/consumer in
12.799/4.972/1.195 seconds. Actual VM tracing observes3/0/0 macro evaluations
and3/1/0 reader calls respectively. The consumer receives two runtime files,
selects no input sources, loads no phase provider and returns [42 99 42]. These
are process stage wall times, not isolated execution timings or RSS claims.

refusal with a still-callable returned closure, argv restoration, foreign-file
preservation, changed BEAM refusal and a real =on_load= instruction whose effect
must never execute. Full reproduction and installed checks are recorded in the
