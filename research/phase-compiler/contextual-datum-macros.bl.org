#+title: Source datum macros through canonical phase bindings
#+date: 2026-10-30

* One compiler and one phase owner
A macro is a binding available at phase p whose function runs at p+1. Its
arguments are syntax represented as datum. Its result is elaborated at the call
site. This datum-v1 contract is explicit; hygienic syntax-v1 retains its existing
syntax objects and template scopes. Both use the same expander and owned session.

#+begin_src clojure
(ns example)
(defmacro add-two [x] (list 'erlang/+ x 2))
(add-two 40)
#+end_src

The Source catalog records add-two without executing it. Compiler/declaration-source
projects the original macro function, including implicit &form and &env arguments.
The declaration's phase-qualified reference selects its constructor in the same
session as compile-time values and helpers. Demand compiles it with the explicit
:datum-macro callable kind. Invocation receives the original form, the visible
local-name map, and unevaluated arguments. Bounded datum conversion and the normal
expander then elaborate the result. Runtime unit admission remains the original
Execution/Loader path; no macro Var is published into ambient Env.

* ABI details that matter
Compiler/macro-header owns documentation, visibility and clause parsing for both
ordinary publication and inert projection. Original macro-fn-form adds &form/&env;
original compile-fn* implements fixed/variadic dispatch and nil for empty macro
rest. Only the root receives nil-rest: nested ordinary functions still get an
empty list. Contextual callable /5 remains an expression; /6 explicitly selects
:expression or :datum-macro and refuses other kinds and non-function macro roots.

Private phase helpers survive Source-free archives. Declaration ordering and
private import rules still refuse early. Passive capture executes no macro;
demanded unapproved effects refuse before execution. Public phase/dependency facts
retain canonical binding references. Source macro implementation ANF is visible;
native SDK macro implementations remain marked opaque rather than receiving an
invented complete effect proof.
