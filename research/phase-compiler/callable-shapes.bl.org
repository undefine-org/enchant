#+TITLE: Callable contracts come from executable structure

* The existing owner

=system.ir/function-shape= describes native function arities and the language's
tagged multi-arity/variadic dispatcher. JavaScript native import metadata already
consumes it. =self-scaffold?= also guides JavaScript emission, footprint and
suspension analysis. These structural facts must agree before a frozen-world
arity checker can use them.

The runtime's =invocable?= is a separate legacy dispatch heuristic: its answer
selects between a local value and a linked global. Changing that answer changes
existing programs. This checkpoint preserves it and introduces no runtime-value
lookup into the structural contract.

#+begin_src beam-lisp :id source-function-contracts
(ns phase.shape.walkthrough
 (:require [compiler :as compiler] [anf :as a] [system.ir :as ir]
           [system.suspension :as suspension]))
(defn shape-node [source]
 (compiler/compile (BeamLisp.Reader/read_one source) (compiler/new-env "shape.walkthrough")))
(let [fixed (ir/function-shape (shape-node "(fn [x] x)"))
      multi (ir/function-shape (shape-node "(fn ([x] x) ([x y] x))"))
      variadic (ir/function-shape (shape-node "(fn [x & rest] x)"))]
 (assert (= #{1} (:arities fixed)))
 (assert (= #{1 2} (:arities multi)))
 (assert (= 1 (:variadic-min variadic)))
 (assert (ir/accepts-arity? variadic 20))
 {:fixed (:arities fixed) :multi (:arities multi) :variadic-min (:variadic-min variadic)})
#+end_src
#+RESULTS: source-function-contracts
: {:multi #{1 2}, :fixed #{1}, :variadic-min 1}

* Printed resemblance grants no contract

A dispatcher must have exactly three fields, an exact atom tag, a literal
integer-keyed map and a nil or correctly formed variadic slot. Fixed keys are
unique. A native slot must accept its fixed count; a variadic slot needs its
minimum plus the packed rest parameter. Native function clauses share one arity.
Malformed or inconsistent shapes yield =nil= (unknown), never an empty proof.

#+begin_src beam-lisp :id tag-is-not-a-string
(let [slot (shape-node "(fn [x y] 42)")
      wrong-tag (a/tup (list (a/lit "$blfn") (a/mapp (list [(a/lit 2) slot])) (a/lit nil)))
      wrong-slot (a/tup (list (a/lit :"$blfn")
                        (a/mapp (list [(a/lit 2) (shape-node "(fn [x] 42)")])) (a/lit nil)))]
 (assert (= false (ir/blfn-value? wrong-tag)))
 (assert (nil? (ir/function-shape wrong-tag)))
 (assert (nil? (ir/function-shape wrong-slot)))
 {:tag-refused true :slot-refused true})
#+end_src
#+RESULTS: tag-is-not-a-string
: {:tag-refused true, :slot-refused true}

* A constructor cannot hide argument evaluation

The canonical self constructor is =let self = (fn [self] INNER) in (self self)=.
Its outer guard is absent and =INNER= is a native function. A different argument
is executable code, even when the outer function ignores its value. Treating
that expression as closure construction previously erased a suspension/effect
obligation; JavaScript emission could drop the argument entirely.

#+begin_src beam-lisp :id arguments-remain-executable
(let [inner (a/fnn (list (a/clause (list) nil (a/lit 42))))
      outer (a/fnn (list (a/clause (list (a/pvar "self")) nil inner)))
      argument (a/recv (list) (a/lit 0) (a/lit :finished))
      node (a/lett "self" outer (a/app (a/var "self") (list argument)))]
 (assert (= false (ir/self-scaffold? node)))
 (assert (= false (suspension/synchronous? node (fn [_] true))))
 {:constructor false :synchronous false})
#+end_src
#+RESULTS: arguments-remain-executable
: {:constructor false, :synchronous false}

Discovery inspects at most256 nested wrappers and returns unknown beyond that
bound. It does not execute initializers or callbacks. Arity compatibility proves
neither matching success, purity, suspension freedom nor native admission.
