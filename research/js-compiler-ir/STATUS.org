* Boundary

The identities are already correct module/function/arity triples. The fix is
in the JavaScript host adapters, with no canonical compiler or ANF changes.

and CompilerData's passive binding-reference, plain-clause and catch-scope
views. Enum predicates stop at the required prefix, callbacks preserve order,
and map keys retain exact equality. The linker still reports unknown names
and unsupported arities.

Native contextual-unit validation retains an explicit BEAM-only refusal.
Its bounded raw-term/class validator is not replaced by a JavaScript shape
approximation. Deterministic ETF serialization also refuses explicitly,
alongside the existing native hashing refusal. Including shared inspection
code does not grant native compilation or execution evidence.
