* Reproduction
Input files were copied to .local/execution-protocol-audit/snapshot and bound to
inputs.json before the attempted analysis; target function bodies are never
executed by the audit. Do not silently analyze a later worktree state under the
same receipt. Restore the matching source hashes or create a new receipt.

The scripts in this directory default to that private snapshot and accept
BL_EXECUTION_AUDIT_SNAPSHOT / BL_EXECUTION_AUDIT_PROGRAM overrides. The ledger
builder requires the private extracted thread-evidence.json in .local; raw
conversation histories and source snapshots are deliberately not duplicated
into this research directory. The recorded finding messages needed to review
the coverage decisions are retained in findings.json.

Run a candidate analysis only after its namespace smoke succeeds, in one capped
process tree with an explicit runtime root and isolated cwd/runtime directory.
The exact command and candidate identity for the failed attempts are recorded
in analysis-status.json. In a checkout, use ./bin/bl. Deliberate sealed-artifact
checks must name the complete candidate, never an installed bl from PATH.

The original failed receipts remain historical evidence. Subsequent implementation
checks name their own sources and runtime identities. The complete 86-case
fixture binding, native admission/ownership implementation and adapter migrations
remain unfinished.
