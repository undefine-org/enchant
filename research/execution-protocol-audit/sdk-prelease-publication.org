unconditionally. It authenticates an existing image row, or returns the actual

protected-forwarder proof. Image/index corruption propagates as an error.

publication is admissible. No execution lease, receipt, SDK identity or staging

this existing shared precheck. The native executor/build-claim ABI does not
change. The filesystem discriminator disappears from this guard.
