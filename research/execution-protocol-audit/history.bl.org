#+title: Historical cases: binding is not execution evidence

* One inventory, actual registered selectors
=findings.json= preserves the original E01-E86 excerpts. =cases.json= binds
reviewed cases to actual file/namespace/deftest names and describes what each
control establishes. It also lists missing variants and baseline/mutation
evidence. Existing tests are reused; the seven proposed fallback files are not
treated as existing tests.

#+begin_src beam-lisp :id historical-binding-inventory
(ns execution.history.walkthrough)
(let [manifest (Jason/decode! (File/read! "research/execution-protocol-audit/cases.json")
                             (list (tuple :keys :atoms)))
      cases (:cases manifest)
      bound (Enum/filter cases #(seq (:selectors %)))
      pending (Enum/filter cases #(seq (:remaining %)))]
 (assert (= 86 (count cases)))
 (assert (= 9 (count bound)))
 (assert (= 86 (count pending)))
 {:original-cases (count cases) :reviewed-bindings (count bound)
  :remaining-evidence (count pending) :complete-goal false})
#+end_src
#+RESULTS: historical-binding-inventory
: {:original-cases 86, :reviewed-bindings 9, :remaining-evidence 86, :complete-goal false}


* Command surface and evidence
=scripts/check-execution-history= audits all 86 without starting BEAM. It exits 1
while any case lacks required bindings or has outstanding evidence. An explicit
selection executes only its reviewed selectors:

#+begin_src sh
systemd-run --user --collect --wait --pipe --working-directory="$PWD" \
  --property=MemoryMax=3G --property=MemorySwapMax=0 \
  --property=RuntimeMaxSec=240 \
  scripts/check-execution-history --cases E01 E02 E04 \
  --out .local/execution/history-review --timeout 210
#+end_src

Output must be absent. =inputs.json= freezes Source/test/tool/native inputs,
the complete floor and the exact case manifest. =plan.json= groups shared tests
once per file. One cold checkout VM verifies its physical root and packaged
compiler key before loading sources. Each file has a fresh Env. The ordinary
TestRT declaration loader discovers names; only selected registered thunks are
retained in that Env, and TestRT runs them with its normal assertion and
exception semantics. No text matching is accepted as discovery evidence.

=execution.json= records actual runtime identity and per-selector counters.
The parent requires the exact requested file/test inventory, positive assertion
counts, zero failures/errors and unchanged inputs before writing
=regressions-passed=. Missing discovery, zero tests/assertions, load errors,
failed children, timeouts, mixed inputs and reused output directories refuse.
Per-case =historical_case_closed= stays false: this runner does not substitute
regression execution for the original failing baseline or causal mutation.

Seventeen Python failure controls pass. A real child rejects missing selectors,
zero assertions, failing assertions and load failures in one serial negative
run. The frozen E01/E02/E04 selection passes 19 assertions in five tests/three
files in 13.299s (whole capped process 13.638s, 284.1M peak,zero swap). All 86 cases
remain open for baseline or listed variant evidence. This is a batch 1
checkpoint; native/protocol closure and final artifact gates remain required.
