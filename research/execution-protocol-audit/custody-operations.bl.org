#+title: Admit the operation before clearing or publishing its bytes

* One operation, actual custody
claim/with-writer! takes native workspace admission before its callback and
releases only custody it acquired. An existing actual owner keeps its descriptor
and cohort. Public diagnostics, caller context and marker values grant nothing.

claim/clear! has two forms. (clear! root) acquires admission itself; (clear! child
root) requires the caller's actual root admission. Both exclude compiler followers
through planning and deletion. Fresh physical resolution bounds descendants,
including paths missing below a symlink. A complete deletion plan is checked
before removal. Permanent anchors retain their inodes; payload symlinks are
unlinked; visible nested workspace claims refuse before any partial deletion.
selfbuild/stage-library-root! uses the second form for priv and ebin.

#+begin_src beam-lisp :eval never
;; API example. The actual executable scenarios are the registered tests below.
(c/with-writer! root "restage SDK inputs"
  (fn [] (c/clear! (Path/join root "priv") root)))
#+end_src

store/install-dir! and sweep-temp! derive one per-entry admission scope outside
the published package. A complete entry remains immutable. Unique temporary
copies publish by checked rename; a sweeper cannot remove an active install,
even its own. Different entries do not take one global store lock.

build/native-one takes producer custody before searching its cached artifact.
Different keys can name the same installed file, so install-artifact! separately
admits that destination. Identical bytes retain their inode; changed bytes get an
atomic replacement. Copy/rename errors propagate and clean the unique temporary.
A nested caller retains its existing source claim.
