#+TITLE: One graph pin for actor and starter code custody

* Retain the frozen graph, preserve the real starter

An application actor and each managed supervisor retain one native graph pin.
The pin covers the graph's frozen managed, native and intrinsic membership.
A pending start has a separate Env-owned pin. Generated init clones that exact
pending ticket into a self-owned pin; monitored registration and final handoff
still precede the user initializer. A public graph map or copied context cannot
supply the native starter receipt.

The fixed internal ABI is =retain_server_start_code!(module)= and
=retain_supervisor_start_code!()=. Both require the actual generated init and
its exact claimed starter receipt; neither accepts a caller-selected graph or
component list. =begin_native_start!= resolves frozen membership from the
parent's admitted frame before its short custody turn.

These are independent code lifetimes. A dead creator before launch releases
its pending custody; an uncertain launch still retains it. Accepted callbacks
and a genuine supervisor may continue after graph retirement, including actual
OTP child restarts. Physical DOWN and the existing guardians reclaim custody.
No second ownership registry is introduced. Pending-start and transition
context transport still carries compatibility maps. Graph pins remove the
module-list cost from code retention; input validation, context capture,
publication checks and dynamic dispatch retain their own costs.

=code_lease_covers_generation?= observes coverage against the original frozen
snapshot. Graph pins use private membership; legacy tickets require every
physical module. The observation grants no admission: real starter, PID,
module, indexed membership and live-ticket checks remain mandatory.

* Observe the actual actor ticket

#+begin_src beam-lisp :id one-actor-graph-pin
(ns execution.actor.pins.walkthrough (:require [reload.generation :as generation]))
(let [graph (generation/prepare!
              {:application-id "actor-pin-walkthrough"
               :stable-namespaces #{"reload.execution"}
               :sources {"actor.pin.walkthrough"
                 (str "(ns actor.pin.walkthrough (:require [reload.execution :as execution])) "
                      "(defserver owner (init [_] (ok nil)) "
                      " (handle-call :read [_ state] "
                      "  (reply {:owned (execution/owned?) :frame (execution/frame)} state))) "
                      "(defn start-owner [] (start owner nil))")}})
      actor (generation/invoke! graph "actor.pin.walkthrough/start-owner" [])]
 (try
  (let [native (elem (first (ets/lookup :beam_lisp_vars (tuple :bl_generation_owner actor))) 1)
        lease (:lease native)
        rows (ets/match_object :beam_lisp_code_leases (tuple (tuple :_ actor (elem lease 2)) true))
        observed (call actor :read)]
   (assert (= 1 (count rows)))
   (assert (= (list (get-in observed [:frame :graph-id])) (elem lease 0)))
   (assert (= true (:owned observed)))
   {:retention :graph-pin :rows (count rows) :owned (:owned observed)})
  (finally (stop actor) (generation/retire! graph))))
#+end_src
