#+TITLE: Scope-owned SDK context tokens share native storage

* Preserve the token, remove the copied graph

=capture_native_context!()= still returns an opaque scope-owned data token.
=resolve_native_context!(token)= still returns the ordinary context map to
native SDK consumers. Binding that map still grants no execution admission.
The internal payload is now a context ID in the existing callback/frame/start
pool. The scope's bounded index contains ordinary overlays and a graph ID,
instead of the full generation. No extra registry or new authority is added.

Capture replaces G with its actual frozen ID before the request crosses Env.
Resolution reads the pooled overlay and obtains the original graph directly
from the shared snapshot in the calling process. A scoped token and a callback
with identical overlays share the same context record, with independent counted
references. Distinct overlays stay distinct. Repeated identical scoped capture
returns its original token without adding another context reference.

Scope destruction releases its data references before removing scoped rows.
This prevents a cycle where a scope-owned context keeps its destroyed graph
snapshot alive. Data references hold no code admission, so graph retirement
does not wait for these tokens. A racing resolve/close reports native-context
retirement. Callback, frame and pending-work references retain their own
lifetimes independently. Context and scope bounds remain enforced.

* Observe sharing and the original local snapshot

#+begin_src beam-lisp :id scoped-context-shared-storage
(ns execution.scoped.contexts.walkthrough (:require [reload.generation :as g]))
(let [graph (g/prepare! {:application-id "scoped-context-walkthrough"
                         :sources {"scoped.context.demo" "(ns scoped.context.demo) (defn value [] 42)"}})
      [token registration] (g/with! graph
                              #(let [token (BeamLisp.Env/capture_native_context!)]
                                 [token (BeamLisp.Execution/register! (fn [] 42))]))]
 (try
  (let [stored (BeamLisp.Env/source_private
                #(elem (first (ets/lookup :beam_lisp_source_lease_domains
                                (tuple (elem token 1) :native_context (elem token 2)))) 1))
        state (BeamLisp.Env/execution_registration_state registration)
        callback (BeamLisp.Env/code_callback_payload (:lease state))
        resolved (BeamLisp.Env/resolve_native_context! token)
        marker (BeamLisp.Env/source_policy_row (tuple :execution_graph_marker (:scope graph)))
        shared (and (some? (:context-id stored)) (= (:context-id stored) (:context-id callback)))
        original (erts_debug/same (:generation resolved) (BeamLisp.Env/execution_graph_generation! marker))]
   (assert shared) (assert original) (assert (not (contains? stored :generation)))
   {:shared-context shared :original-local-snapshot original :copied-generation (contains? stored :generation)})
  (finally (BeamLisp.Execution/close! registration) (g/retire! graph))))
#+end_src
