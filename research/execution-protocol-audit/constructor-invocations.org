* Preserve dispatch before specializing ownership

operand names an actual compiler-proved canonical declaration. It keeps the

The generated call uses the shared versioned =anf/invoke= constructor. No legacy
remote =Rt.invoke= spelling is synthesized. Direct native constructor routes
keep their existing selected-recipe receiver.

The only new runtime entry is:

#+begin_example

through =start-declared!=, which rechecks the actual selected generation,
original class, sealed recipe and first-order arguments. Opaque constructor
arguments keep the existing embedded fallback.

existing Source frame. This preserves lookup/initializer effects, argument
order, arity handling and the Source target policy. The helper grants no
execution frame, graph, class, registration, or lifecycle custody from a public
descriptor. Native fixture tests introduce plain, remote and multi-arity

while a declared native identity must succeed through the same fallback.
