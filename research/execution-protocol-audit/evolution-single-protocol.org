Evolution now has one transition protocol. upgrade!, rehearse!, prepare-upgrade!,
commit-upgrade! and cancel-upgrade! always use native grants and opaque bundles.
The application-owner? selector and five raw-spec RPC fallback branches are gone.

only through native opaque context storage; public maps no longer select a codec.

grant issuance rechecks the live origin and exact owner. No second registry or
execution authority is introduced. Unsupported unbound transitions deliberately
refuse; native ordinary data requests remain usable through existing admission.
