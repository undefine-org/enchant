#+TITLE: Managed context stays out of OTP init packets and restart specs

* Restore only the actual starter's context

Pending rows already held graph/context IDs, but the parent still sent a second
full context through OTP. Server and supervisor init compared it with the
starter's authoritative context. That redundant packet copied G across another
process boundary. Managed supervisor restart specs also retained one full
context per child.

Managed init packets now carry a fixed =:native-context= marker in that field.
The child validates the marker and its genuine one-shot starter, then restores
the context selected by that actual private receipt. No packet supplies a
context or graph selector. Native class/PID/lease/membership checks and the
user-init ordering remain unchanged. Public start arguments and naming remain
compatible; the private init packet grammar changes.

Managed child specs carry the existing opaque scope-owned context token. Their
native supervisor retains the graph, so its scope remains alive for restart
after logical graph retirement. The child-start wrapper resolves the original
shared graph locally, then authenticates its actual indexed supervisor owner
before starting children. Copying a token or binding its data cannot create a
supervisor. Public managed child-spec construction also returns the token,
preventing the descriptor from exposing a full native context to Source.

* Observe the actual restart descriptor

#+begin_src beam-lisp :id managed-restart-context-token
(ns execution.start.wire.walkthrough (:require [reload.generation :as g]))
(let [graph (g/prepare! {:application-id "managed-wire-walkthrough" :stable-namespaces #{"proc.super"}
                         :sources {"managed.wire.demo"
                           "(ns managed.wire.demo (:require [proc.super :as super]))
                            (defserver owner (init [_] (ok nil)) (handle-call :read [_ st] (reply 42 st)))
                            (super/defsupervisor tree (child :owner owner nil {}))
                            (defn start-tree [] (start-link tree))"}})
      tree (g/invoke! graph "managed.wire.demo/start-tree" [])]
 (try
  (let [spec (elem (erlang/apply :supervisor :get_childspec (list tree :owner)) 1)
        context (elem (nth (elem (:start spec) 2) 2) 1)
        child (elem (first (Supervisor/which_children tree)) 1)
        retired (g/retire! graph)]
   (assert (not (erlang/is_map context))) (assert (= :bl_native_context (elem context 0)))
   (assert (= 42 (call child :read))) (assert (= :waiting (:status retired)))
   {:restart-context (elem context 0) :reply (call child :read) :retirement (:status retired)})
  (finally (Supervisor/stop tree :normal 5000) (g/retire! graph))))
#+end_src
