* Cause and correction
qualify-artifact-generation copied the checked-in seed into a private image
but reused demo-artifact-production's current-floor receiver boot. A real AOT
Source edit changes the compiler key. Without Bootstrap.install!, the copied
predecessor was not admitted as the previous-generation compiler; the drift
gate rejected its bootstrap units before Core could be initialized.

The generation producer now calls the existing Bootstrap.install!/2 before
AOT.boot, with its private ebin and explicit copied seed directory. The
installer authenticates manifest bytes and complete unit closure, and derives
the staging namespace list from that manifest. Build drivers are excluded.
Only its exact current/previous-generation results are accepted. No manifest,
compiler key, staging flag or authority is manufactured by the driver.

The predecessor's stable loaded module MD5s must remain unchanged. The actual
input keys are recorded separately from predecessor keys and must not change
during boot. This installation exists only in the private producer image;
it does not publish a checkout compiler or qualify a product. Produced B and
C still undergo the strict fresh-receiver, preboot/integrity and byte-for-byte
reproduction checks. The ordinary demo receiver still requires a current floor.
