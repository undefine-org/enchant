* Candidate
vm.native/build-all! first obtains its validated source-native root selection.
It loads build only for a nonempty selection, then uses the same mapcat action,
producer, error handling and result shape. No declaration/root validation or
actual native production is removed. The same process next call recaptures the
selection, so adding a native declaration must still trigger normal work.

The candidate regression executes this exact source under a private namespace,
with a marker-only producer: six assertions pass on Build. It checks empty
selection without a producer, newly added native sources in the same process,
and symlink refusal before calling the producer. Exact SDK qualification follows.

* Coordinator source-parts experiment
A writable copy of the identical compiler-floor coordinator, same program and
cwd, takes 7.54 s without data, 6.30 s with predecessor source parts and native
syntax, and 6.25 s on a fresh repeat. Separating the inputs gives 6.39 s for
parts alone, 7.34 s for native declarations alone, 7.26 s for neither again,
and 6.45 s for both. Native-declaration copying is excluded from implementation.
The candidate imports only source parts through a separate content-addressed
Nix data path, without retaining the predecessor's complete image closure or
requiring the target SDK. No runtime reader/authorization code changes. Its
normal generation/content/checksum/shape checks and parser fallback remain.
