#+title: Portable release FHS receiver control

This control runs one immutable portable release using the existing bounded KVM receiver in =portable-runtime.nix=. Pass its top-level release store path as =release=; the adapter checks the release manifest and executable digest before selecting the existing receiver.

The receiver materializes the pinned OTP runtime libraries, glibc and C++ ABI as ordinary FHS files. BusyBox applet links remain relative inside its private chroot. The running drop cannot see =/nix/store=. The existing =portable-runtime.bl= checks arithmetic, native JSON loading and encoding, and JSON decoding. The output retains =receiver.log= and =result.json=.

This qualifies that declared receiver baseline. It does not establish compatibility with every distribution, libc version, CPU, native extension or deployment environment. Main-thread qualification owns evaluation and execution; this fixture does not introduce another executor.
