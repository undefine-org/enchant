<h1>One event. One shared world.<br>A view for every viewer.</h1>
<p class="lede">Events describe a change. The BEAM decides.<br>Each screen is a projection of the state its viewer can see.</p>
<p class="intro">Follow a task click through the amber path, then follow the state values through the purple path back to the page. Typing a filter takes the short route through <code>:assign</code> and session locals. Everything below belongs to the same Live system.</p>

<title id="live-title">Live: the whole system in one graph</title>
<desc id="live-description">A browser sends event data over a WebSocket to Live on the BEAM. Assign and navigate update session locals. An intent is authorized, then a registered performer returns transaction data, a no-op, or a refusal. The runtime commits a transaction to a shared or private connection. Shared commits notify observing viewer sessions. Each viewer reads its guarded shared database snapshot, optional private session database snapshot and locals. Its view returns a Hiccup tree with event data. Live diffs the old and new trees and sends keyed patches and CSS back to the browser. The browser applies them to its DOM. A viewer session process owns locals, subscriptions and the previous tree and can resume across a brief transport disconnect.</desc>

<div class="reading">
<p><strong>State has an owner.</strong>Shared facts belong to a database connection. The viewer session owns its private world and locals. A view queries database <em>values</em> at a basis—a fixed snapshot of the facts.</p>
<p><strong>An intent asks; an assign sets.</strong><code>:intent</code> requests a registered server operation. <code>:assign</code> changes a local value; <code>:navigate</code> changes the local route. Shared commits wake every observing session.</p>
<p><strong>The runtime performs effects.</strong>The view describes a tree and events as data. The runtime interprets events, submits returned transaction data, listens for commits and sends patches. A registered performer is ordinary code and can also perform effects.</p>
